1. Overview

FM Readiness is an Autodesk Revit add-in that bridges the gap between BIM authoring and Facilities Management handover. It audits MEP assets for COBie and FM data completeness, scores readiness at element, group, category, and overall levels, provides a guided parameter editor for fixing missing data, supports bulk updates across flexible scopes, and exports FM metadata to IFC-aligned outputs — all from a dockable pane inside Revit.

Facility Management teams rely on accurate, complete data to operate buildings efficiently after construction handover. In practice, BIM models are often delivered with inconsistent or missing FM parameters — manufacturer names, model numbers, serial IDs, warranty dates, and COBie classification fields. FM Readiness solves this by embedding a data-quality workflow directly inside Revit, so teams can audit, fix, and export FM-ready data without leaving their authoring environment.

2. Features

Audit Results Dashboard

  • Summary cards — Readiness %, Ready/Missing counts, Total audited
  • Component & Type group score badges with tooltips
  • Scope toggle: All fields vs. Required-only
  • View modes: Combined, Component, Type
  • Row actions: Fix, Locate (select + zoom), View

Parameter Editor

  • Selection auto-sync with lock / unlock
  • Scope picker: Selection, Active view, Type instances, Category
  • Multi-select tray with bulk operations
  • Safe-apply with confirmation & impact preview
  • Field validation — ISO dates, numeric ranges

COBie & Legacy Modes

  • COBie Editor with preset-driven field definitions
  • Legacy FM Editor for FM_* parameters
  • "Ensure COBie Parameters" with optional cleanup
  • COBie validation rules (required, unique, date format)
  • Rooms, Spaces, Levels support for COBie context

Export Workflows

  • FM Sidecar: .fm_params.json keyed by IFC GlobalId
  • IFC Export: IFC4DTV with user-defined property sets
  • Automatic IFC pset configuration setup
  • Compatible with Digital Twin viewers
  • Configurable export scope per category

Configurable Preset System

  • JSON preset files: cobie-core, fm-legacy, custom
  • Define component & type fields per category
  • Required / unique / date validation rules
  • Alias parameter mapping
  • Group labels for organized field display

MEP Category Support

  • Mechanical Equipment
  • Duct Terminals & Accessories
  • Pipe Accessories
  • Rooms, MEP Spaces, Levels (COBie context)
  • Extensible via preset configuration

4. Workflow

Step 1 — Audit

Select target categories and run a readiness audit. The plugin scans every element against the active preset's checklist and generates a scored report — highlighting which fields are populated, which are missing, and the overall readiness percentage for each group and category.

Step 2 — Fix & Edit

Click "Fix" on any failing element to jump directly into the parameter editor with missing fields highlighted. Edit individually or use bulk scopes (selection, view, type, category) to apply values across hundreds of elements at once, with a confirmation dialog showing exact impact before committing.

Step 3 — Export

Once readiness is satisfactory, export the enriched data. Choose IFC4DTV export with auto-configured user-defined property sets, or generate a lightweight .fm_params.json sidecar file keyed by IFC GlobalId — ready for ingestion by Digital Twin platforms and CAFM/CMMS systems.

5. Technical Highlights
