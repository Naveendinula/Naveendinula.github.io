Digital Twin Platform (BIM + FM)

Web-based Digital Twin platform for BIM visualization, graph-powered relationship querying, HVAC/FM operational analysis, embodied carbon workflows, and LLM-powered natural language interface.

Project Summary

Languages: JavaScript — 57% · Python — 43%
Backend: FastAPI · IfcOpenShell · Neo4j · NetworkX · SQLite
Frontend: React · Vite · Three.js · React Three Fiber
AI/ML: LLM RAG pipeline · Neo4j Knowledge Graph
Repository: github.com/Naveendinula/DigitalTwin

1. Overview

Most BIM tools are either authoring-heavy or disconnected from day-to-day facilities operations. This platform bridges that gap by combining IFC processing, interactive 3D navigation, graph-powered BIM querying, HVAC/FM operational analysis, work-order management with CMMS sync, embodied carbon and occupancy workflows — all within an authenticated, job-scoped multi-user web application.

For FM teams: convert model data into actionable work-order and service-impact workflows. For Digital Twin teams: query building relationships as a graph (systems, spaces, equipment, materials). For sustainability teams: quantify embodied carbon at element level with override controls.

3. Feature Highlights

BIM Ingestion & 3D Viewing

  • Upload IFC, convert to GLB, extract metadata and spatial hierarchy
  • Navigate with orbit/pan/zoom, isolate regions, section-cut, and inspect element properties
  • File-hash dedupe for identical IFC uploads and model reopen without re-upload

Graph-Powered BIM Query

  • Traverse relationships: FEEDS, SERVES, IN_SYSTEM, CONTAINED_IN, HAS_MATERIAL
  • Query by IFC type, storey, material, name, related node, relationship type, and hop depth
  • Optional graph view for visual network exploration (reagraph)

HVAC/FM Operational Intelligence

  • Analyze equipment-to-terminal-to-space service chains
  • Inspect physically connected vs. inferred system-associated terminals
  • Link selected results directly back to 3D model highlighting

LLM Natural Language Interface

  • RAG + Neo4j knowledge graph for natural language BIM queries
  • Ask questions like "What space does HRU-408 serve?" or "Which equipment have serial numbers?"
  • Structured data retrieval with context-aware responses

Work Orders & CMMS Integration

  • Create, update, prioritize, assign, and close work orders tied to model elements
  • Export in CSV/JSON using COBie-compatible column naming
  • Push/pull work-order sync with CMMS adapters and webhook ingestion

Embodied Carbon & Occupancy

  • Calculate embodied carbon from BIM-derived quantities and material mappings
  • Apply material/type/element-level overrides for calibration
  • Visualize occupancy snapshots and space heatmaps for operational scenario analysis

4. Architecture

Backend (FastAPI, Python)

  • IFC conversion and extraction pipeline (IfcOpenShell, IfcConvert)
  • Graph build artifact (NetworkX) + graph query backend (Neo4j default, NetworkX optional)
  • HVAC/FM, embodied carbon, validation, occupancy, work orders, CMMS sync
  • SQLite for auth/session audit + FM operation records
  • Cookie-based JWT auth with refresh-token rotation and CSRF protection

Frontend (React, Vite, Three.js, R3F)

  • 3D viewer and interaction tools (orbit, section cut, isolation, X-ray)
  • Floating operational panels (EC, HVAC/FM, Graph, Work Orders, IDS, Occupancy)
  • Auth-aware API usage and selection-linked workflows
